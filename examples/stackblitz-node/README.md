# ZeltJS Quickstart

This is a standalone Node.js example for the ZeltJS StackBlitz playground.

- Open the preview to call `GET /`.
- Edit `src/app.ts`; the development server restarts automatically.
- Compare `src/app.ts` with `src/server.ts` to see the boundary between the
  application core and its Node.js runtime entry.

Run it locally with:

```sh
npm install
npm run dev
```
