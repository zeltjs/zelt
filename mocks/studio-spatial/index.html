READING THE MAP

表示とコードの対応

小さい箱は実在する1つのメソッド。囲みはその宣言元クラスです。実際の名前を使い、意味で複数の関数を合成しません。

緑の矢印はメソッドを「呼ぶ」。青の丸端の線は property / getter を「読む」。灰色の破線はクラスの「継承」です。property を架空の関数 node に変換しません。interface の実装関係はクラス詳細に記載します。

注文の地図は8メソッドと DrizzleService.db、認証の地図は JwtService.verify と JwtConfig.secret / EcJwtConfig.secret を表示します。getter は実際のアクセサー宣言として1つだけ表示します。

対象メソッド内の注入先への呼出・property 読み取りを実コードと照合します。コンストラクター本体、無名コールバック、ORM・KV・フレームワークの内部まで網羅した図ではありません。

層はこの fixture のファイル配置・パッケージに基づく固定配置です。責務を推測して新しいクラスを作ったものではありません。
